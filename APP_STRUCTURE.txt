SUN DIRECTION APP
=================

1. WHAT THIS APP DOES
---------------------
- A user enters a city name.
- The app calls the Nominatim geocoding API to resolve that city into latitude/longitude.
- Every 10 seconds, the app calculates the sun's current azimuth and elevation.
- The compass view renders where the sunlight is coming from in real time.

4. FILE ROLES
-------------
- src/App.java
  Application entry point. Opens the Swing UI.

- src/MainFrame.java
  Main window and control logic. Handles user actions, timer refresh, and status text.

- src/GeocodingService.java
  Calls OpenStreetMap Nominatim over HTTP and parses latitude/longitude from JSON.

- src/SunCalculator.java
  Computes sun azimuth and elevation from time and coordinates.

- src/SunCompassPanel.java
  Paints the visual compass and sun location.


5. HOW THE SUN DIRECTION IS CALCULATED
--------------------------------------
- Input: latitude, longitude, current UTC time
- Convert time to Julian Date
- Compute solar orbital values
- Compute solar declination and equation of time
- Compute local true solar time and hour angle
- Convert those values into:
  - azimuth: compass direction (0=N, 90=E, 180=S, 270=W)
  - elevation: height above horizon


6. HOW THE VIEW WORKS
---------------------
- The compass uses a sky-dome projection:
  - center = directly overhead (90 deg elevation)
  - outer edge = horizon (0 deg elevation)
- The sun icon is placed using:
  - angle = azimuth
  - distance from center = based on elevation
- If elevation is below 0, the app switches to night mode.

8. LIMITATIONS
--------------
- City lookup requires internet access.
- Timezone display is longitude-based estimation, not full timezone database resolution.
- Solar position is accurate enough for visualization, not for scientific surveying.
